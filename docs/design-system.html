ReUse

Sistema de Identidade Visual · v1.0

Uma linguagem visual inspirada em etiquetas de brechó e carimbos de verificação, porque cada objeto reaproveitado carrega a marca de uma segunda vida.

Conceito

O ponto de partida não é o verde genérico de "sustentabilidade". É o universo físico do re-uso: a etiqueta pendurada num casaco de brechó, o carimbo de aprovado num processo de doação, o furo de picote de uma nota fiscal destacável. Esses elementos viram o vocabulário visual do produto, do ícone da marca aos badges de condição do item.

Componentes

Botões, tags e cards

Botões

Primário: musgo sólido. Secundário: contorno, mesma cor. Nunca usar argila em botão de ação comum.

Chips de condição do item
Como novo Usado · bom estado Para peças

Estilo etiqueta: fonte mono, borda tracejada, sem preenchimento.

Tag Card (evolução do SectionCard)

Card com "furo de picote" no canto esquerdo, referência ao destacável de uma etiqueta. Usado para blocos de conteúdo e para anúncios de item.

Elemento de assinatura

O carimbo de re-uso

Um selo circular de borda tracejada, levemente rotacionado, como um carimbo de mão real. É o único elemento "ousado" do sistema e se repete de forma consistente: no ícone do app, em divisores de seção e em confirmações dentro do fluxo.
